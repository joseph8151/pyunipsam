# 편입샘 사업 구축 기획서 — Part 2. 상품·목차·가격

> 모든 수요·전환·난이도 등급은 **[추정]**이다. 실측 데이터가 없으므로 수치(판매량, 전환율)는 만들지 않았다.
> 가격은 'A안(권고 출시가)'이다. 사용자 가설가는 8장에서 'B안'으로 따로 시험한다.
> 대학별 상품은 **[미확인] 대학은 요강 확인 전 '보류'**다.

## 범례
- 난이도 `제작/검수`: 하·중·상 (영어 문항은 AI 초안 비중이 높아 제작 '중', 수학은 풀이 검증이 필요해 검수 '상', 전공은 전문가 검수 필수)
- 우선순위: **P1** 출시 1~3개월, **P2** 4~6개월, **P3** 6개월 이후, **보류** 공식 요강 확인 후 결정, **통합** 다른 상품에 합침
- 쪽수 설계 원칙: 200P = 문제 약 75 + 해설 약 115 + 요약·부록 약 10. 해설이 문제의 1.5배 이상이 되도록 설계(해설이 핵심 차별점).

## 7. 카테고리별 상세 목차·페이지 구성

### 7-1. 표준 200P 문제집 구조 (영어)
| 구간 | 쪽 | 내용 |
|---|---|---|
| 표지·이용안내 | 2 | 기준 요강, 개정일, 정오표 QR/링크 |
| 학습 가이드·플래너 | 4 | 진도표, 시간 배분 |
| 핵심 개념 요약 | 8 | 유형별 1쪽 요약 |
| 문제편 | 약 75 | 난이도 ★1~★3, 6~8문항/쪽 (독해는 지문 1쪽+문제) |
| 정답 | 2 | 일괄 정답표 |
| 상세 해설 | 약 100 | 정답 근거, 오답 선지 분석, 오답 원인 태그 |
| 오답노트 | 6 | 인쇄용 양식 |
| Final Review | 6 | 반복 오답 유형 20문항 |
| 부록 | 4 | 유형별 체크리스트, 정오표 |

### 7-2. 수학 200P 구조
- 문제 약 60쪽(1쪽 2~3문항, 수식 공간), 해설 약 120쪽(정석 풀이+단축 풀이+검증 계산), 개념 요약 12쪽, 공식 정리 4쪽. **풀이 분량이 많으므로 문항 수를 영어보다 낮게(약 180~200)** 설계한다.

### 7-3. 대학별 모의고사 구조 (예: 한양대 자연계 수학)
1. 시험 정보 (모집요강 근거: 25문항, 객관식 20+단답형 5, 70분)
2. 모의고사 3회(각 25문항) — 실제 배점·시간
3. 정답·해설, 채점표, 영역별 취약 분석, 시간 배분 기록표
4. 변경 이력(연도별 형식 변화) — 한양 35→40문항(인문), 영어 폐지(자연) 같은 변화 [확인]

### 7-4. 카테고리별 개요
- **어휘:** 일 단위(Day 1~N) + 복습 테스트 + 누적 시험.
- **문법:** 개념→기본→응용→실전 4단계. 유형당 문항 수 편중 방지(유형별 최소 문항 수 정의).
- **독해/논리:** 지문당 난이도 표기, 지문 어휘 수, 풀이 권장 시간, 구조도 해설.
- **수학:** 단원별 난이도(기본/응용/고난도), 연산 검증 로그, 출제 범위 표.
- **면접·서류:** 보조 자료이며 대학별 실제 시행 여부·제출서류를 확인한 대학만 포함.

## 8. 상품 가격표

### 8-1. A안 (권고 출시가) — 시중가 대비 1.5~4배 수준

| 구분 | 설명 | 가격(원) |
|---|---|---|
| 무료 | 진단 테스트, 오답노트·플래너 | 0 |
| 보조 | 워크북·플래너 | 4,900~14,000 |
| Final Review / 파이널 | 100제 내외 | 14,000~24,000 |
| 단일 영역 100P | 어휘·모의고사 등 | 29,000~39,000 |
| 전문 문제집 200P | 문법·독해·논리·수학 200제 | 49,000~69,000 |
| 대학별 모의고사 | 3~5회 | 29,000~49,000 |
| 종합 패키지 300P | 번들 | 89,000~119,000 |

### 8-2. B안 (사용자 가설가) — 고가 시나리오 시험용
단일 100P 99~129천, 200P 179~220천, 패키지 279~330천, 대학별 79~149천, Final Review 29~49천.
- **리스크:** 확인된 서점 교재 정가(24,300~44,100원)의 4~10배. 신규 브랜드·무후기 상태로는 검증되지 않음.
- **시험 방법:** 대학별 모의고사 1개와 200P 1개에 한해 B안을 **한정 노출(A/B 테스트)**하고, 표본 규모와 결과를 기록한 뒤 판단. 전환율 기준을 사전에 정하지 않고 결과를 사후에 숫자로 해석하는 방식은 피한다.

### 8-3. 가격 책정 원칙
- 쪽수·문항 수가 아니라 **검수 비용·시험 적합성**으로 가격 근거를 설명.
- 개정 시 구매자 무료 업데이트(1시즌).
- 환불·청약철회 정책은 전자상거래법상 디지털 콘텐츠 규정에 맞춰 공지(법률 확인 필요 [미확인]).
- 번들 할인으로 객단가를 올리되 정가의 가짜 할인 표시 금지.
