# 편입샘 사업 구축 기획서 — Part 3. 제작·홈페이지·블로그·로드맵

## 9. AI 제작 및 전문가 검수 프로세스

**원칙:** AI는 초안을 만들고, 사람이 정답과 해설과 출제 범위를 검수한다. 검수 미완료 문항은 판매하지 않는다.

### 9-1. 공통 파이프라인
| 단계 | 내용 | 담당 | 통과 기준 |
|---|---|---|---|
| 1. 범위 정의 | 대학 요강 근거, 문항 수, 시간, 난이도 분포 확정 | 기획 | 요강 링크·캡처 보관 |
| 2. 초안 생성 | 문항 설계 표(유형×난이도) 기반 AI 생성 | AI | 표와 100% 일치 |
| 3. 1차 자동 점검 | 중복·표절 유사도, 선지 길이/패턴 편향 점검 | 스크립트 | 기존 공개 기출과 문장 단위 중복 없음 |
| 4. 독립 풀이 | 별도 AI 세션/사람이 정답을 **해설을 보지 않고** 풀이 | AI+사람 | 출제 정답과 일치 |
| 5. 전문가 검수 | 영어·수학 전문 검수자가 정답·해설 확인 | 사람 | 검수 체크리스트 서명 |
| 6. 조판·교정 | 수식·표기·페이지 | 사람 | 교정 2회 |
| 7. 시범 풀이 | 소수 수험생 시범 풀이로 체감 난이도·소요시간 확인 | 사람 | 시간 허용범위 |
| 8. 배포·정오표 | 워터마킹, 버전 관리, 정오표 | 운영 | 버전 기록 |

### 9-2. 편입영어 검수 체크리스트
- 문법: 문법 오류 문항에서 **오류가 정확히 1개**인가, 다른 선지도 문법적으로 틀리지 않은가.
- 오답 선지가 문맥상 정답이 될 가능성(복수 정답) 점검 — 가장 흔한 AI 오류.
- 지문: 논리 비약, 사실 오류, 어휘 수준·길이 기준 일치.
- 해설: 정답 근거 문장과 해설이 일치하는가, 해설이 다른 선지를 정답으로 암시하지 않는가.
- 어휘: 동의어 문항에서 사전적으로 구분 가능한가.
- 대학별: 문항 수·시간·형식이 요강과 일치하는가.

### 9-3. 편입수학 검수 체크리스트
- **계산 검증:** 심볼릭 계산 도구(예: SymPy 등)로 모든 정답을 독립 계산. AI 풀이만으로 정답 확정 금지.
- 정답 유일성(수치형은 값, 객관식은 한 선지만 일치), 정의역·조건 누락 확인.
- 수식 표기 일관성, 조판 오류(첨자, 적분 구간) 확인.
- 출제 범위: 편입 수준 범위 이탈 여부, 대학 요강에 명시된 범위 대조.
- 풀이 2종(정석/단축)을 제공할 경우 서로 일치하는지 확인.
- 난이도: 풀이 단계 수와 소요 시간으로 정량 분류.

### 9-4. 전공 필기
전공은 해당 분야 전문가(대학원 이상 또는 실무 경력자) 검수를 전제로 하며, 검수자 확보 전 제작하지 않는다.

### 9-5. 저작권·윤리
- 공개 기출 문항 복제 금지, 구조·출제 경향만 참고해 독창 문항 제작.
- 대학 이름은 '대비'를 의미하는 서술적 사용에 한정하고, 대학 공식 교재로 오인될 표현 금지.
- 합격 보장·후기 조작 금지. 후기는 실제 구매자 동의 후 게시.

### 9-6. 인력/비용 구조 [추정]
검수가 병목이다. 월 신규 출시 가능량은 **'검수자 확보 인원 × 검수 가능 문항 수'**로 결정한다. 첫 3개월은 영어 검수 1~2명, 수학 검수 1명을 최소 확보 대상으로 두고, 실제 인건비는 견적으로 확정한다(수치 미제시).

## 10. 홈페이지 전체 메뉴 구조

### 10-1. 메인 메뉴
```
편입샘 (필요한 문제만, 정확하게)
├─ 편입영어
│   ├─ 어휘
│   ├─ 문법
│   ├─ 독해
│   ├─ 논리
│   └─ 종합·모의고사
├─ 편입수학
│   ├─ 미적분학
│   ├─ 선형대수
│   ├─ 공학수학(확인된 출제 대학이 있을 때만)
│   └─ 종합·모의고사
├─ 대학별 모의고사
│   ├─ 대학 선택 (상품화 확인된 대학만 노출)
│   ├─ 영어만 / 수학만 / 영어+수학 필터
│   └─ 요강 기준 연도·변경 이력
├─ 전공 필기  (검수자 확보 후 오픈)
├─ 편입 면접·서류
│   ├─ 면접
│   └─ 학업계획서·자기소개서
├─ COMPLETE 패키지
├─ 무료 샘플
│   ├─ 진단 테스트
│   ├─ 샘플 PDF(해설 포함)
│   └─ 오답노트·플래너
└─ 이용 안내
    ├─ 구매·다운로드 방법
    ├─ 환불·청약철회
    ├─ 정오표
    ├─ 검수 기준 공개
    ├─ 저작권/재배포 금지
    └─ 문의
```

### 10-2. 상품 상세페이지 구성
1. 상품명 / 시험 기준(몇 학년도 모집요강 기준, 링크)
2. 이런 분께 / 이런 분께는 맞지 않음 (과장 방지)
3. 구성: 쪽수, 문항 수, 난이도 분포, 목차(펼침)
4. **샘플 미리보기**: 문제 5문항 + 해설 3문항
5. 제작·검수 방식과 개정 이력
6. 학습 방법 가이드 (소요 시간 [추정]이면 명시)
7. 가격, 번들, 업데이트 정책
8. FAQ (환불, 인쇄, 기기, 재다운로드)
9. 관련 상품, 무료 진단 테스트 링크
10. 금지: 합격 보장, 합격률, 검증 불가 후기, 가짜 마감 타이머

### 10-3. 운영·기술 요건
- 결제: PG 연동, 통신판매업 신고 및 사업자 표기 의무 [법률 확인 필요 — 미확인]
- 파일 보호: 구매자별 워터마킹(이름/메일 표기), 다운로드 횟수 제한, 이중 공유 방지 안내
- 이메일/알림톡으로 정오표·개정본 공지
- 분석: 검색 유입, 샘플 다운로드, 장바구니, 구매 전환 측정(실측 데이터 축적 후 판단)

## 11. 네이버 블로그 콘텐츠 전략

### 11-1. 운영 사이클
**정보성 3~4편 : 상업성 1편** 사이클 (한 사이클 약 2주 [추정, 조정 가능]).

| 유형 | 비중 | 예시 주제 |
|---|---|---|
| 정보성 | 75~80% | 실제 문항 분석, 오답 원인, 수험생 질문 답변, 대학별 변경사항 |
| 상업성 | 20~25% | 신규 상품 소개(샘플 포함), 업데이트 공지, 번들 안내 |

### 11-2. 콘텐츠 기둥
1. **대학별 변경사항:** "한양대 자연계가 2026학년도부터 영어를 보지 않는 이유와 준비 방식" 같은 요강 기반 글(공식 출처 링크 필수). [확인된 사례 활용]
2. **오답 분석 시리즈:** 오답 선지가 '왜' 그럴듯한지 해부 — 샘플 문항 직접 공개.
3. **수험생 질문 Q&A:** 커뮤니티·문의에서 나온 질문을 정리(개인정보 제거).
4. **풀이 전략/시간 배분:** 40문항 70분, 25문항 70분 등 실제 시험 형식 기준 시간표.
5. **편입 과정 안내:** 일반편입 vs 학사편입, 지원 자격, 일정 달력.
6. **AI 제작 과정 공개:** 검수 체크리스트와 실제 정오표 사례 → 신뢰 축적.

### 11-3. 검색 의도 설계 (키워드 나열 대신)
| 검색 의도 | 콘텐츠 형태 |
|---|---|
| "한양대 편입 자연계 영어 폐지" (정보 탐색) | 요강 근거 정리 + 준비 방법 |
| "편입 문법 오류 찾기 푸는 법" (방법 탐색) | 풀이 절차 + 샘플 3문항 |
| "편입수학 책 추천" (비교) | 선택 기준 가이드(타사 비하 없이) + 무료 진단 |
| "OO대 편입 모의고사" (구매 의향) | 상품 소개(상업성 편) |

### 11-4. 작성 규칙
- 제목 구조·도입부를 돌려 쓰지 않는다. 글마다 서로 다른 질문으로 시작.
- 모든 사실에는 출처(대학 입학처 등) 표기, 확인 못한 것은 '확인 필요'로 표시.
- 상품 글에는 샘플, 대상 독자, 대상이 아닌 독자를 함께 적는다.
- 반복적 홍보 문구, 과장 표현, 합격 보장 문구 금지.
- 유튜브 쇼츠/네이버 클립은 블로그 글의 문항 1개를 30~45초로 풀어주는 형식(채널 성과는 실측 후 판단).

### 11-5. 3개월 편집 달력 (초안)
- 1~2주차: 대학별 시험 변경 정리 2편, 진단 테스트 안내 1편
- 3~6주차: 한양·중앙·외대 대학별 시험 분석 시리즈 (각 학교 정보+샘플)
- 7~9주차: 파이널 학습 계획, 오답 분석 시리즈
- 10~12주차: 시험 직전 체크리스트, 시험 후기(공식 정보 위주), 2027 시즌 준비 로드맵

## 12. 첫 3개월 상품 출시 로드맵

시작일을 2026-11-02로 가정한 12주 계획. (1월 중순 필기 시즌과의 간극을 고려해 **1~8주차에 시즌형 상품**을 집중한다.)

| 주차 | 사업 | 제작 | 마케팅 |
|---|---|---|---|
| 1 | 브랜드·도메인·결제·통신판매업 신고 확인, 경쟁 가격 조사, 대학알리미 시장 데이터 수집 | 한양·중앙·외대 **공식 요강 PDF 대조**, 문항 설계표 | 블로그 개설, 기본글 |
| 2 | 홈페이지 오픈(무료 샘플) | 진단 테스트 30문항, 오답노트 템플릿 | 무료 샘플 홍보 글 |
| 3~4 | 환불/약관 정비, 검수자 확정 | 한양 자연계 수학 모의 제작·수학 검증 | 대학별 변경사항 글 2편 |
| 5 | **#37 한양 수학 모의 출시** | 한양 영어, 중앙 영어 제작 | 출시 글 1 + 정보글 3 |
| 6 | **한양 인문 영어 출시** | 외대 영어 제작 | 정보글 |
| 7 | **중앙대 영어 출시** | 파이널 100제 제작 | 정보글 |
| 8 | **외대 영어 출시** | 어휘 300제 제작 | 정보글+상품글 |
| 9 | 파이널 100제 출시, 판매 데이터 1차 점검 | 문법 오류 200제 제작 | 시즌 직전 정리 |
| 10 | 어휘 300제 출시 | 미분법 제작 | |
| 11 | 문법 오류 200제 출시 | 논리완성 제작 | |
| 12 | 3개월 회고(전환율·환불·문의·정오표 건수 집계), 가격 A/B 결과 정리, 2027시즌 계획 | 적분/선형대수 확장 기획 | |

### 12-1. 성공 여부를 판단하는 지표 (목표 수치는 실측 후 설정)
- 무료 샘플 다운로드 → 구매 전환율, 상품별 환불률, 정오표 건수, 검수 지연일수, 블로그 유입 검색어.
- 판매량·전환율 목표는 현재 근거 데이터가 없어 **설정하지 않는다.** 2주 단위로 측정하며 수치를 쌓은 뒤 목표를 정한다.

### 12-2. 주요 리스크
| 리스크 | 대응 |
|---|---|
| 고가 정책이 시장에서 수용되지 않음 | A안 시작 + 한정 A/B |
| 대학 요강 변경으로 상품 무효 | 요강 연도 표기, 변경 시 무료 업데이트 |
| AI 문항 오류 | 독립 풀이+전문가 검수 의무화 |
| PDF 불법 유통 | 구매자 워터마킹, 이용약관 |
| 11~12월 신규 사이트의 신뢰 부족 | 무료 샘플·정오표 공개·검수 과정 공개 |
| 상표/대학명 사용 분쟁 | '대비' 서술적 사용, 비공식 명시 |
| 검수 병목 | 출시 속도를 검수 인력에 맞춰 조정 |

### 12-3. 즉시 확인이 필요한 항목 (할 일)
1. 한양·중앙·외대의 **공식 요강 PDF**로 문항 수·배점 재확인 (중앙대 수학 문항 수 포함)
2. 성균관·경희·건국·서강 등 미확인 대학 요강 수집 후 상품화 여부 결정
3. 2027학년도 요강 공개 시(11~12월) 전면 업데이트
4. 서점·스마트스토어에서 타사 PDF/교재 가격 표본 수집
5. 통신판매업 신고, 전자상거래법 디지털 콘텐츠 환불 규정 법률 확인
