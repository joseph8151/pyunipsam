Q.01정답 ④미분법 · 곱의 미분과 합성함수

■ 문제

함수 f(x) = x2e3x 에 대하여 f′(1)의 값은?

■ 출제 의도

곱의 미분법과 합성함수의 미분(연쇄법칙)을 동시에 적용하는지 확인한다.

■ 핵심 개념

  • 곱의 미분: (uv)′ = u′v + uv′ — 두 함수의 변화를 모두 반영한다.
  • 합성함수의 미분: (e^{g(x)})′ = g′(x)e^{g(x)} — 지수 위 함수의 도함수를 곱한다.
  • 로그미분: 곱·거듭제곱이 섞인 함수는 ln 을 취하면 합으로 바뀌어 계산이 단순해진다.

■ 정석 풀이

  1. 곱의 미분: f′(x) = (x²)′·e3x + x²·(e3x)′
  2. (e3x)′ = 3e3x (연쇄법칙) 이므로 f′(x) = 2x·e3x + 3x²·e3x = e3x(2x + 3x²)
  3. x = 1 대입: f′(1) = e3(2 + 3) = 5e3

[단축 풀이]

로그미분: ln f = 2 ln x + 3x → f′/f = 2/x + 3 → f′(1) = f(1)·(2+3) = e3·5 = 5e3

■ 계산 검증

f′(x)/f(x) = 2/x + 3 에서 x=1: 5 → f(1)=e³ 이므로 5e³. 두 방법의 결과가 일치한다.

■ 선택지·오답 분석

①e³ = f(1). 미분하지 않고 함숫값을 고른 경우
②2e³ = 첫 항 (x²)′e3x만 계산하고 둘째 항 누락
③3e³ = 연쇄법칙의 3을 곱하지 않고 2x·e3x + x²·e3x 로 계산
④정답
⑤6e³ = 곱의 미분을 '미분의 곱'(x²)′·(e3x)′ = 2x·3e3x 으로 착각

■ 함정 포인트

체인룰의 3 을 빼먹거나 곱의 미분 두 항 중 하나를 놓치는 실수가 가장 빈번하다. 오답 ①②③⑤ 가 모두 이 실수에서 나온다.

■ 변형 출제

f(x)=x³e^{−x} 처럼 지수의 부호·차수를 바꿔도 로그미분 f′/f = 3/x − 1 로 같은 방식이 통한다.

Q.02정답 ②적분법 · 부분적분

■ 문제

정적분 ∫01 x·ex dx 의 값은?

■ 출제 의도

부분적분의 부호와 상·하한 대입 순서를 정확히 처리하는지 확인한다.

■ 핵심 개념

  • 부분적분: ∫u dv = uv − ∫v du, u 는 미분하면 단순해지는 함수(x)를 택한다.
  • 정적분은 원시함수를 먼저 구한 뒤 상한 − 하한으로 대입한다(하한 값 누락 주의).
  • 피적분함수가 양수이면 정적분도 양수 — 부호로 오답을 1차 필터링한다.

■ 정석 풀이

  1. u = x, dv = exdx 로 두면 du = dx, v = ex
  2. ∫ x ex dx = x ex − ∫ ex dx = (x − 1)ex + C
  3. [(x − 1)ex]01 = (0) − (−1) = 1

[단축 풀이]

결과 꼴을 알고 있으면 (x − 1)ex 를 미분해 x ex 임을 확인하고 바로 대입한다.

■ 계산 검증

d/dx[(x − 1)ex] = ex + (x − 1)ex = x ex ✓. 피적분함수가 구간에서 양수이므로 값도 양수(1)이다.

■ 선택지·오답 분석

①0 = 상한 값(x=1)만 취하고 하한 값(−1)을 빼지 않음
②정답
③e − 1 = x를 무시하고 ∫exdx 로 계산
④e = x ex 자체를 원시함수로 착각 ([x ex] = e)
⑤2e − 1 = 부분적분 부호 실수 ((x + 1)ex 를 원시함수로 사용)

■ 함정 포인트

[(x−1)e^x]₀¹ 에서 상한 값 0 만 남기고 하한 값 −1 을 빼지 않아 0 을 고르는 실수가 빈번하다.

■ 변형 출제

구간을 [0,2] 로 바꾸면 [(x−1)e^x]₀² = e² + 1 이 된다.

Q.03정답 ③선형대수 · 고유값과 대각합

■ 문제

행렬 A = [[4, 1], [2, 3]] 에 대하여 A2의 모든 고유값의 합은?

■ 출제 의도

고유값의 거듭제곱 성질과 대각합(trace)·행렬식 관계를 활용해 계산량을 줄이는지 확인한다.

■ 핵심 개념

  • A 의 고유값이 λ 이면 A² 의 고유값은 λ² 이다 (Ax = λx → A²x = λ²x).
  • tr(A) = 고유값의 합, det(A) = 고유값의 곱.
  • tr(A²) = (tr A)² − 2 det A (2×2 행렬의 항등식).

■ 정석 풀이

  1. 특성방정식: λ² − (4+3)λ + (4·3 − 1·2) = λ² − 7λ + 10 = 0 → λ = 2, 5
  2. A²의 고유값은 λ² = 4, 25 → 합은 4 + 25 = 29

[단축 풀이]

tr(A²) = (tr A)² − 2 det A = 49 − 20 = 29 (고유값을 구하지 않고 바로 계산)

■ 계산 검증

A² = [[18, 7], [14, 11]] 을 직접 계산하면 대각합 18 + 11 = 29 ✓.

■ 선택지·오답 분석

①7 = A의 고유값의 합(제곱하지 않음)
②10 = det A (고유값의 곱)
③정답
④49 = (tr A)². '제곱의 합'과 '합의 제곱'을 혼동
⑤100 = det(A²). 고유값의 곱의 제곱을 계산

■ 함정 포인트

‘제곱의 합’(Σλ²)과 ‘합의 제곱’((Σλ)²)을 혼동해 49 를 고르거나, det 를 고유값의 합으로 착각한다.

■ 변형 출제

A 가 대칭행렬이면 고유값이 모두 실수이므로 tr(A²) = Σλ² ≥ 0 임을 이용하는 변형이 가능하다.

Q.04정답 ③극한 · 무리식의 유리화

■ 문제

limx→∞ ( √(x2 + 3x) − x ) 의 값은?

■ 출제 의도

∞ − ∞ 꼴을 유리화로 해소하고 최고차항으로 나누어 극한을 구하는지 확인한다.

■ 핵심 개념

  • ∞ − ∞ 는 유리화(켤레식)로 분수 꼴로 바꾼다.
  • x→∞ 에서 √(x²+ax) = x√(1+a/x) ≈ x(1 + a/(2x)) (이항근사).
  • 분모·분자를 최고차항 x 로 나눠 극한을 정리한다.

■ 정석 풀이

  1. ∞ − ∞ 부정형이므로 켤레식 √(x²+3x) + x 를 분자·분모에 곱한다
  2. 분자: (x² + 3x) − x² = 3x, 분모: √(x²+3x) + x
  3. 분모를 x 로 나누면 √(1 + 3/x) + 1 → x→∞ 에서 2
  4. 극한 = 3x / (x·2) = 3/2

[단축 풀이]

√(x²+ax) ≈ x + a/2 (x 가 매우 클 때) 이므로 차는 a/2 = 3/2

■ 계산 검증

x = 10⁸ 대입: √(10¹⁶ + 3·10⁸) − 10⁸ ≈ 1.49999999… → 3/2 ✓.

■ 선택지·오답 분석

①0 = ∞ − ∞ 를 ‘같은 크기’로 보고 0 으로 판단
②1 = 분모를 계산하며 √ 안의 계수를 잘못 처리(3/2 를 정수로 반올림)
③정답
④3 = 분모의 + x 를 누락하고 3x/x 로 계산
⑤∞ = 부정형을 발산으로 오판

■ 함정 포인트

분모의 + x 를 빼먹거나, ∞ − ∞ 를 0 으로 단정하는 실수. 유리화 후 반드시 분모의 두 항을 모두 x 로 나눠야 한다.

■ 변형 출제

√(x²+ax) − x → a/2 로 일반화되므로 a 를 바꾼 문항은 계산 없이 풀 수 있다.

Q.05정답 ③미분 응용 · 최대·최소

■ 문제

구간 [0, 4] 에서 함수 f(x) = x3 − 6x2 + 9x + 1 의 최댓값은?

■ 출제 의도

임계점과 구간 끝점의 함숫값을 모두 비교하는 최대·최소 문제의 절차를 확인한다.

■ 핵심 개념

  • 닫힌구간 최대·최소 정리: 최댓값·최솟값은 임계점 또는 구간 끝점에서 나온다.
  • 극값이 구간 내부에 있어도 끝점 값을 반드시 함께 비교한다.
  • 함수를 인수분해해 두면 극값의 구조를 계산 없이 파악할 수 있다.

■ 정석 풀이

  1. f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3) → 임계점 x = 1, 3 (모두 구간 안)
  2. 후보 : f(0) = 1, f(1) = 5, f(3) = 1, f(4) = 64 − 96 + 36 + 1 = 5
  3. 최댓값 = 5 (x = 1 과 x = 4 에서 동시에 도달)

[단축 풀이]

f(x) − 1 = x(x − 3)² 로 인수분해되므로 [0,4] 에서 x(x−3)² 의 최댓값을 보면 x=1 (4) 과 x=4 (4) 가 같다 → f 의 최댓값 5

■ 계산 검증

x(x−3)² 를 전개하면 x³ − 6x² + 9x ✓. x=1: 1·4 = 4, x=4: 4·1 = 4 ✓ → f = 4 + 1 = 5.

■ 선택지·오답 분석

①1 = 최솟값 (f(0) = f(3) = 1)
②4 = 구간 끝점의 x 좌표(4)를 값으로 착각
③정답
④6 = 임계점 함숫값의 합 f(1) + f(3) = 5 + 1
⑤9 = 도함수의 값 f′(0) = 9 와 혼동

■ 함정 포인트

x = 4 (끝점)의 함숫값을 비교하지 않고 극대값 f(1) = 5 만 보고 풀 수 있어 정답은 우연히 맞더라도 절차 점검이 중요하다. 끝점이 더 크면 답이 달라진다.

■ 변형 출제

구간이 [−1, 4] 이면 f(−1) = −15 이므로 최솟값 후보가 바뀌지만 최댓값 5 는 그대로다.

Q.06정답 ③적분 응용 · 넓이

■ 문제

곡선 y = x2 과 직선 y = 2x 로 둘러싸인 부분의 넓이는?

■ 출제 의도

교점을 구해 적분 구간을 정하고 위·아래 함수를 구분해 넓이를 계산하는지 확인한다.

■ 핵심 개념

  • 두 곡선 사이의 넓이: ∫(위쪽 함수 − 아래쪽 함수)dx, 구간은 교점에서 정한다.
  • 이차함수와 직선(현) 사이 넓이 = |a|(β−α)³/6 (1/6 공식).
  • 위·아래를 뒤집으면 음수가 나오므로 부호로 오류를 검산한다.

■ 정석 풀이

  1. 교점: x² = 2x → x = 0, 2
  2. 구간 [0, 2] 에서 2x ≥ x² (위: 직선, 아래: 포물선)
  3. 넓이 = ∫₀² (2x − x²) dx = [x² − x³/3]₀² = 4 − 8/3 = 4/3

[단축 풀이]

포물선과 현으로 둘러싸인 넓이 공식: (|a|/6)(β − α)³ , a = 1, β−α = 2 → 8/6 = 4/3

■ 계산 검증

구간을 1/N 로 쪼개 수치적분하면 ≈ 1.3333 ✓.

■ 선택지·오답 분석

①2/3 = 구간을 [0, 1] 로 잘못 잡음
②1 = 유사 값 방지용 선지 (수치적분으로 배제)
③정답
④2 = 유사 값 방지용 선지 (수치적분으로 배제)
⑤8/3 = ∫₀² x² dx = 8/3 로 포물선 아래 면적만 계산

■ 함정 포인트

교점을 구하지 않고 [0, 1] 에서 계산하거나, 한 곡선 아래 넓이만 구하는 실수. 먼저 그림을 그려 위·아래를 정하라.

■ 변형 출제

y = x² 과 y = x 로 바꾸면 ∫₀¹ (x − x²)dx = 1/6.

Q.07정답 ③급수 · 수렴반경

■ 문제

멱급수 Σn=1∞ n·xn / 2n 의 수렴반경은?

■ 출제 의도

비율판정법으로 수렴반경을 구하고 계수 n 이 반경에 영향을 주지 않음을 이해하는지 확인한다.

■ 핵심 개념

  • 수렴반경 R = 1 / lim |an+1/an| (계수 기준) 또는 비율판정법으로 |x| < R.
  • 다항식 계수(n, n², …)는 수렴반경을 바꾸지 않는다 (경계점 수렴 여부만 달라질 수 있다).
  • 수렴반경과 수렴구간은 다르다 — 경계점은 따로 확인한다.

■ 정석 풀이

  1. an = n xn/2n 에 비율판정법: |an+1/an| = ((n+1)/n)·|x|/2
  2. n → ∞ 에서 (n+1)/n → 1 이므로 극한은 |x|/2
  3. |x|/2 < 1 ⟺ |x| < 2 → 수렴반경 R = 2

[단축 풀이]

Σ(x/2)ⁿ 의 공비 x/2 에 다항 계수 n 이 붙어도 수렴반경은 바뀌지 않는다 → R = 2

■ 계산 검증

((n+1)/n)·(1/2) 를 n = 10⁶ 에서 계산하면 ≈ 0.5000005 → 극한 1/2 = 1/R ✓.

■ 선택지·오답 분석

①1/2 = 극한값(1/R)을 반경으로 착각
②1 = 계수 n 때문에 반경이 줄어든다고 오판
③정답
④4 = 2² (분모의 제곱)
⑤∞ = 지수함수 급수와 혼동

■ 함정 포인트

비율의 극한이 1/2 로 나오면 그것이 반경이 아니라 1/R 이다. R = 2 로 뒤집는 마지막 단계를 빼먹기 쉽다.

■ 변형 출제

분모를 3ⁿ 으로 바꾸면 R = 3. 분자를 n! 로 바꾸면 R = 0 이 된다.

오답 원인 태그: 역수 처리 누락

Q.08정답 ④다변수 · 방향도함수

■ 문제

함수 f(x, y) = x2y + y2 의 점 (1, 2) 에서 벡터 u = (3/5, 4/5) 방향의 방향도함수 Duf 의 값은?

■ 출제 의도

기울기 벡터와 단위벡터의 내적으로 방향도함수를 구하는지 확인한다.

■ 핵심 개념

  • Duf = ∇f · u (u 는 반드시 단위벡터).
  • 기울기 ∇f 는 f 가 가장 빠르게 증가하는 방향이고, 그 크기가 방향도함수의 최댓값이다.
  • 단위벡터가 아니면 크기로 나눠 정규화한 뒤 내적한다.

■ 정석 풀이

  1. fx = 2xy → (1, 2) 에서 4 / fy = x² + 2y → 1 + 4 = 5 → ∇f = (4, 5)
  2. u = (3/5, 4/5) 는 크기 1 인 단위벡터 (9/25 + 16/25 = 1)
  3. Duf = ∇f · u = 4·3/5 + 5·4/5 = 12/5 + 20/5 = 32/5

[단축 풀이]

단위벡터 확인 후 ∇f·u 를 한 줄로 계산: (12 + 20)/5 = 32/5

■ 계산 검증

수치 미분으로 (f(1 + 0.6h, 2 + 0.8h) − f(1,2))/h (h → 0) ≈ 6.4 = 32/5 ✓.

■ 선택지·오답 분석

①4 = fx 만 사용
②5 = fy 만 사용
③9 = fx + fy 의 합
④정답
⑤32 = 단위벡터화 없이 (3, 4) 를 그대로 사용 (4·3 + 5·4)

■ 함정 포인트

방향 벡터를 정규화하지 않아 32 를 고르는 실수가 가장 흔하다. 문제의 u 가 이미 단위벡터인지 크기를 먼저 확인하라.

■ 변형 출제

u 를 (3, 4) 로 주면 |u| = 5 로 나눠 같은 값 32/5 를 얻는 문제로 변형된다.

오답 원인 태그: 정규화 누락 / 편미분 항 선택

Q.09정답 ③미분방정식 · 1계 선형

■ 문제

y′ + 2y = e−x, y(0) = 2 를 만족하는 해 y(x) 에 대하여 y(1) 의 값은?

■ 출제 의도

적분인자법으로 일반해를 구하고 초기조건으로 상수를 정확히 결정하는지 확인한다.

■ 핵심 개념

  • 1계 선형 y′ + P y = Q 의 적분인자: μ = e^{∫P dx}.
  • 일반해 = 특수해 + 제차해 (yh = C e−2x).
  • 초기조건은 일반해 전체에 대입해 C 를 구한다 — 특수해만 대입하지 않는다.

■ 정석 풀이

  1. 적분인자 μ = e2x → (y·e2x)′ = e2x·e−x = ex
  2. y·e2x = ex + C → y = e−x + C e−2x
  3. y(0) = 1 + C = 2 → C = 1 → y = e−x + e−2x
  4. y(1) = 1/e + 1/e²

[단축 풀이]

미정계수법: 특수해 yp = A e−x 를 대입하면 −A + 2A = 1 → A = 1, 제차해 C e−2x 를 더한다

■ 계산 검증

y = e^{−x} + e^{−2x} 를 방정식에 대입하면 y′ + 2y = −e^{−x} − 2e^{−2x} + 2e^{−x} + 2e^{−2x} = e^{−x} ✓, y(0) = 2 ✓.

■ 선택지·오답 분석

①2/e² = 제차해만 사용 (y = 2e−2x)
②1/e = 특수해만 사용 (초기조건 무시, C = 0)
③정답
④1/e + 2/e² = y(0) = 2 를 C 에 그대로 대입 (C = 2)
⑤2/e = 유사 값 방지용 선지 (대입 검산으로 배제)

■ 함정 포인트

y(0) = 2 를 일반해 y = e−x + C e−2x 의 C 에 그대로 넣는 실수. 1 + C = 2 로 C = 1 임을 거쳐야 한다.

■ 변형 출제

우변을 e−2x 로 바꾸면 제차해와 겹쳐 공명이 일어나 특수해가 x e−2x 꼴이 된다.

오답 원인 태그: 초기조건 처리 / 일반해 구성

Q.10정답 ②선형대수 · 계수와 영공간

■ 문제

행렬 A = [[1, 2, 3], [2, 4, 6], [1, 0, 1]] 에 대하여 동차연립방정식 Ax = 0 의 해공간의 차원은?

■ 출제 의도

행의 일차종속성을 찾아 rank 를 구하고 계수-영공간 정리(rank + nullity = n)를 적용하는지 확인한다.

■ 핵심 개념

  • 계수-영공간 정리: rank(A) + nullity(A) = (열의 수).
  • 행이 서로 일차종속이면 rank 가 줄어든다 — det = 0 은 정사각행렬의 신호.
  • 동차연립방정식 Ax = 0 은 항상 자명해 x = 0 을 가진다 — ‘해가 없음’은 불가능.

■ 정석 풀이

  1. R₂ = 2R₁ 이므로 두 번째 행은 첫 번째 행의 상수배 (일차종속)
  2. R₁ 과 R₃ 는 서로 상수배가 아니므로 일차독립 → rank A = 2
  3. rank + nullity = 3 (열의 수) → nullity = 3 − 2 = 1

[단축 풀이]

행 하나가 다른 행의 배수임을 눈으로 확인하면 rank 2, nullity 1 로 바로 결정된다 (det A = 0 도 같은 신호).

■ 계산 검증

수치 계산으로 rank(A) = 2 를 확인했다. 해공간 기저: (−1, −1, 1)ᵗ → A(−1,−1,1)ᵗ = (−1−2+3, −2−4+6, −1+0+1) = (0,0,0) ✓.

■ 선택지·오답 분석

①0 = A 가 가역(full rank)이라고 가정
②정답
③2 = rank 와 nullity 혼동
④3 = 변수의 수(열의 수)를 해공간 차원으로 착각
⑤동차계는 항상 자명해를 가지므로 해가 없을 수 없다

■ 함정 포인트

rank 와 nullity 를 혼동해 2 를 고르는 실수가 가장 많다. 질문이 묻는 것은 ‘해공간’(영공간)의 차원이다.

■ 변형 출제

세 번째 행을 (2, 0, 2) 로 바꿔도 rank 는 2, nullity 는 1 로 같다.
