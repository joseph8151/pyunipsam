01정답 ③극한 · 테일러 전개

■ 문제

limx→0 (e2x − 1 − 2x) / x2 의 값은?

■ 출제 의도

0/0 꼴에서 테일러 전개 또는 로피탈 정리를 선택해 빠르게 계산하는지 확인한다.

■ 핵심 개념

  • ex = 1 + x + x²/2! + … 의 테일러 전개를 이용하면 ‘0/0’ 극한이 다항식 비교로 바뀐다.
  • (eax − 1 − ax)/x² → a²/2 (a = 2 이면 2).
  • 로피탈 정리는 분모·분자 모두 0 일 때 미분해서 다시 극한을 보는 방법이다 (2회 적용).

■ 정석 풀이

  1. e2x = 1 + 2x + (2x)²/2! + … = 1 + 2x + 2x² + …
  2. 분자 = 2x² + (고차항) → 극한 = 2

[단축 풀이]

로피탈 2회: (2e2x − 2)/(2x) → 4e2x/2 → x=0에서 2

■ 계산 검증

x = 0.01 대입: (e0.02 − 1.02)/0.0001 ≈ (1.0202013 − 1.02)/0.0001 ≈ 2.01 → 2에 근접한다.

■ 선택지·오답 분석

①0 = 1차항이 소거되는 것만 보고 0으로 판단
②1 = ex 전개 계수를 그대로 사용(2x → x)
③정답
④4 = (2x)² 에서 1/2! 을 누락
⑤∞ = 분모가 0이라 발산으로 오판

■ 함정 포인트

1/2! 계수를 빼먹어 4 를 고르거나, 1차항이 소거되는 것만 보고 0 으로 단정하는 실수가 빈번하다.

■ 변형 출제

(e^{ax} − 1 − ax)/x² → a²/2 로 일반화되어 a 만 바꾼 문항은 즉시 풀린다.

오답 원인 태그: 전개 계수 실수 / 부정형 오판

02정답 ③급수 · 부분분수와 망원급수

■ 문제

급수 Σn=1∞ 1 / (n(n + 2)) 의 값은?

■ 출제 의도

부분분수 분해로 망원급수(telescoping)를 인식하는지 확인한다.

■ 핵심 개념

  • 부분분수 분해 1/(n(n+2)) = ½(1/n − 1/(n+2)) 로 망원급수(telescoping)를 만든다.
  • 망원급수는 앞 두 항(1, ½)만 남고 뒤쪽은 0 으로 수렴한다.
  • 부분합 SN 의 극한이 급수의 합이다.

■ 정석 풀이

  1. 1/(n(n+2)) = (1/2)(1/n − 1/(n+2))
  2. 부분합 SN = (1/2)[(1 + 1/2) − (1/(N+1) + 1/(N+2))]
  3. N → ∞ 이면 (1/2)(3/2) = 3/4

[단축 풀이]

남는 항은 처음 두 항(1, 1/2)뿐이다. (1/2)(1 + 1/2) = 3/4

■ 계산 검증

S₁ = 1/3, S₂ ≈ 0.458, S₃ ≈ 0.525, S₄ ≈ 0.567, S₅ ≈ 0.595 … 가 0.75에 접근한다.

■ 선택지·오답 분석

①1/2 = 앞의 계수 1/2만 남기고 괄호 안을 1로 계산
②2/3 = 부분합이 접근하는 값이 아님(부분합 검산으로 배제)
③정답
④5/6 = 부분합이 접근하는 값이 아님(부분합 검산으로 배제)
⑤1 = 1/n − 1/(n+1) 꼴의 망원급수로 착각

■ 함정 포인트

괄호 안 계수 ½ 를 빼먹어 3/2 가 되거나, 1/n − 1/(n+1) 꼴로 착각해 1 을 고르는 실수.

■ 변형 출제

1/(n(n+3)) 이면 (1/3)(1 + 1/2 + 1/3) = 11/18.

03정답 ①적분 · 부분적분(삼각함수)

■ 문제

정적분 ∫0π/2 x cos x dx 의 값은?

■ 출제 의도

부분적분에서 삼각함수의 부호 처리와 경계값 대입을 정확히 하는지 확인한다.

■ 핵심 개념

  • 부분적분에서 u 는 미분하면 단순해지는 함수(x), dv 는 적분이 쉬운 함수(cos x)를 택한다.
  • (sin x)′ = cos x, (cos x)′ = −sin x 의 부호를 항상 확인한다.
  • 피적분함수가 [0, π/2] 에서 0 이상이므로 값은 양수 (π/2 − 1 ≈ 0.57).

■ 정석 풀이

  1. u = x, dv = cos x dx → du = dx, v = sin x
  2. ∫ x cos x dx = x sin x − ∫ sin x dx = x sin x + cos x + C
  3. [x sin x + cos x]₀^{π/2} = (π/2 + 0) − (0 + 1) = π/2 − 1

[단축 풀이]

d/dx(x sin x + cos x) = sin x + x cos x − sin x = x cos x 임을 확인하고 곧바로 대입한다.

■ 계산 검증

구간을 잘게 쪼갠 수치적분 값 ≈ 0.570796 = π/2 − 1 ✓.

■ 선택지·오답 분석

①정답
②π/2 = cos x 항(−1)을 누락
③π/2 + 1 = 부호 실수 (+ cos 항을 반대로 대입)
④π − 1 = x sin x 의 값을 π/2 가 아닌 π 로 계산
⑤1 − π/2 = 전체 부호 반전 (음수 → 피적분함수가 양수이므로 불가능)

■ 함정 포인트

부호가 음수인 선지(⑤)는 피적분함수의 부호만으로 즉시 제거할 수 있다. 부호 검산을 습관화하라.

■ 변형 출제

∫₀^{π/2} x sin x dx = 1 로 바뀌며 같은 방식으로 풀린다.

04정답 ④선형대수 · 고유값과 행렬식

■ 문제

행렬 A = [[2, 0], [1, 3]] 에 대하여 det(A2 + A) 의 값은?

■ 출제 의도

행렬 다항식의 고유값이 λ 의 다항식으로 변환됨을 이용해 계산량을 줄이는지 확인한다.

■ 핵심 개념

  • 삼각행렬의 고유값은 대각성분이다.
  • p(A) 의 고유값은 p(λ). 행렬식은 고유값의 곱이다.
  • det(AB) = det(A)·det(B) — A² + A = A(A + I) 로 인수분해해 계산한다.

■ 정석 풀이

  1. A 는 하삼각행렬이므로 고유값은 대각성분 2, 3
  2. A² + A 의 고유값 = λ² + λ → 2² + 2 = 6, 3² + 3 = 12
  3. det(A² + A) = 6 × 12 = 72

[단축 풀이]

det(A² + A) = det(A)·det(A + I) = 6 × 12 = 72 (A(A+I) 로 인수분해)

■ 계산 검증

A² = [[4, 0], [5, 9]], A² + A = [[6, 0], [6, 12]] → det = 6·12 − 0·6 = 72 ✓.

■ 선택지·오답 분석

①18 = tr(A² + A) = 6 + 12 (대각합과 행렬식 혼동)
②36 = det(A)² = det(A²) 만 계산
③60 = 유사 값 방지용 선지 (직접 계산으로 배제)
④정답
⑤144 = 12² (고유값 곱의 제곱 오류)

■ 함정 포인트

tr(대각합)과 det(행렬식)을 혼동해 18 을 고르거나, A² 의 행렬식만 구해 36 을 고르는 실수.

■ 변형 출제

고유값이 a, b 이면 det(A² + A) = (a² + a)(b² + b) 로 일반화된다.

오답 원인 태그: trace/det 혼동

05정답 ②다변수 · 이중적분

■ 문제

영역 D = {(x, y) : 0 ≤ y ≤ x ≤ 1} 에 대하여 ∬D xy dA 의 값은?

■ 출제 의도

삼각형 영역의 적분 순서를 정하고 안쪽 적분 후 바깥 적분을 정확히 수행하는지 확인한다.

■ 핵심 개념

  • 적분 영역을 먼저 그림으로 확인하고 안쪽 적분의 변수 범위를 결정한다.
  • 피적분함수 xy 가 x, y 에 대해 대칭이므로 y ≤ x 와 x ≤ y 영역의 적분 값은 같다.
  • 정사각형 영역에서는 ∬xy = (∫x)(∫y) = ¼ (분리 가능).

■ 정석 풀이

  1. 0 ≤ y ≤ x, 0 ≤ x ≤ 1 이므로 ∫₀¹ ( ∫₀ˣ x y dy ) dx
  2. 안쪽: x · [y²/2]₀ˣ = x · x²/2 = x³/2
  3. 바깥: ∫₀¹ x³/2 dx = 1/8

[단축 풀이]

대칭성: 정사각형 [0,1]² 에서 ∬xy = 1/4 이고 y ≤ x 영역은 그 절반 → 1/8

■ 계산 검증

수치적분 ≈ 0.12500 = 1/8 ✓.

■ 선택지·오답 분석

①1/12 = 유사 값 방지용 선지 (직접 계산으로 배제)
②정답
③1/6 = 안쪽 적분 후 x 인수를 곱하지 않고 ∫ x²/2 계산
④1/4 = 영역을 정사각형 [0,1]² 로 착각
⑤1/2 = 유사 값 방지용 선지

■ 함정 포인트

영역을 정사각형으로 착각해 1/4 를 고르거나 안쪽 적분 결과에 곱해야 할 x 를 빠뜨려 1/6 이 나온다.

■ 변형 출제

영역이 0 ≤ x ≤ y ≤ 1 이어도 대칭성으로 값은 1/8 로 같다.

06정답 ③급수 · 등비급수의 변형

■ 문제

급수 Σn=0∞ (n + 1) / 3n 의 값은?

■ 출제 의도

Σ(n+1)rⁿ = 1/(1−r)² 공식을 알고 있는지, 또는 등비급수를 미분해 유도할 수 있는지 확인한다.

■ 핵심 개념

  • 등비급수 Σrⁿ = 1/(1−r) (|r| < 1) 를 항별 미분하면 계수 n 이 붙은 급수의 합이 나온다.
  • Σ(n+1)rⁿ = 1/(1−r)² 는 공식으로 외워 둘 가치가 있다.
  • 수렴 조건 |r| < 1 을 먼저 확인한다.

■ 정석 풀이

  1. Σn≥0 rn = 1/(1 − r) 의 양변을 r 로 미분하면 Σ n rn−1 = 1/(1 − r)²
  2. Σn≥0 (n + 1) rn = 1/(1 − r)²
  3. r = 1/3 → 1/(2/3)² = 9/4

[단축 풀이]

공식 Σ(n+1)rⁿ = 1/(1 − r)² 에 r = 1/3 을 바로 대입한다.

■ 계산 검증

처음 200 항의 합을 계산하면 2.25 = 9/4 ✓.

■ 선택지·오답 분석

①3/2 = 계수 n + 1 을 무시한 등비급수 Σ(1/3)ⁿ = 3/2
②2 = 유사 값 방지용 선지 (부분합 검산으로 배제)
③정답
④3 = 유사 값 방지용 선지
⑤9/2 = 정답에 2를 곱한 값 (미분 시 계수 오류)

■ 함정 포인트

(n+1) 계수를 무시한 3/2 를 고르는 실수. 계수 n 이 붙으면 반드시 미분 공식을 떠올려야 한다.

■ 변형 출제

r = 1/2 이면 1/(1/2)² = 4.

07정답 ③미분 응용 · 극값

■ 문제

함수 f(x) = x e−x (x ≥ 0) 의 최댓값은?

■ 출제 의도

도함수의 부호 변화로 극대점을 찾고 극댓값을 계산하는지 확인한다.

■ 핵심 개념

  • 도함수가 0 이 되는 점의 좌우 부호 변화로 극대·극소를 판정한다.
  • e−x 는 항상 양수이므로 부호 분석에서 소거해도 된다.
  • x → ∞ 에서 f → 0 이므로 극대점이 최대점이 된다.

■ 정석 풀이

  1. f′(x) = e−x − x e−x = (1 − x) e−x
  2. f′ = 0 → x = 1 이고, x < 1 에서 f′ > 0, x > 1 에서 f′ < 0 → x = 1 에서 극대(최대)
  3. f(1) = 1·e−1 = 1/e

[단축 풀이]

e−x > 0 이므로 f′ 의 부호는 (1 − x) 의 부호와 같다. 극대점이 x = 1 로 즉시 결정된다.

■ 계산 검증

x 를 0 에서 5 까지 0.001 간격으로 대입하면 최댓값 0.36788 = 1/e (x = 1) ✓.

■ 선택지·오답 분석

①0 = f(0) = 0 (경계값)
②1/e² = f(2) = 2/e² 와 혼동하거나 지수만 계산
③정답
④2/e = 분모 처리 오류
⑤e = ex 를 e−x 로 착각해 f(1) = e 로 계산

■ 함정 포인트

e−x 의 지수 부호를 놓치면 e 를 고른다. f(1) = 1·e−1 에서 지수 −1 을 반드시 대입하라.

■ 변형 출제

f(x) = x² e−x 이면 극댓값은 x = 2 에서 4/e².

오답 원인 태그: 지수 부호 실수

08정답 5적분 · 삼각함수의 거듭제곱

■ 문제

정적분 ∫0π/2 sin3x dx = p/q (p, q는 서로소인 자연수) 일 때, p + q 의 값을 구하시오.

■ 출제 의도

홀수 거듭제곱의 치환 적분(sin 한 개를 떼어 cos로 치환)을 정확히 수행하는지 확인한다.

■ 핵심 개념

  • 홀수 거듭제곱은 sin 하나를 떼고 cos 로 치환하면 다항 적분이 된다.
  • 월리스 공식: ∫₀^{π/2} sinⁿx dx = (n−1)!!/n!! (n 홀수일 때 π/2 계수 없음).
  • 치환 시 상·하한도 함께 바꾼다 (x: 0→π/2, t = cos x: 1→0).

■ 정석 풀이

  1. sin³x = (1 − cos²x) sin x, t = cos x 로 치환하면 dt = −sin x dx
  2. ∫0π/2 sin³x dx = ∫01 (1 − t²) dt = 1 − 1/3 = 2/3
  3. p = 2, q = 3 → p + q = 5

[단축 풀이]

월리스 공식: ∫0π/2 sin³x dx = (2/3)·1 = 2/3 (홀수 차수: (n−1)!!/n!!)

■ 계산 검증

정적분 값 2/3 ≈ 0.667. sin³x ≤ sin x 이고 ∫0π/2 sin x dx = 1 이므로 값은 1보다 작다 ✓.

■ 선택지·오답 분석

답안 작성단답형은 보기가 없으므로 값을 직접 도출해야 한다. 답은 p+q = 5 (2/3 자체를 쓰지 않도록 주의).
흔한 실수치환 후 상·하한을 바꾸지 않거나 부호(−)를 처리하지 않아 −2/3 또는 1/3 이 나오는 경우

■ 함정 포인트

치환 후 상·하한을 바꾸지 않거나 −부호를 처리하지 않아 −2/3 또는 1/3 이 나오는 실수.

■ 변형 출제

sin⁵x 이면 8/15 (p + q = 23).

오답 원인 태그: 치환 한계 실수 / 부호

09정답 36선형대수 · 고유값

■ 문제

행렬 A = [[5, 2], [2, 2]] 의 두 고유값 중 큰 값을 λ 라 할 때, λ2 의 값을 구하시오.

■ 출제 의도

특성방정식으로 고유값을 구하고 큰 값을 정확히 선택하는지 확인한다.

■ 핵심 개념

  • 2×2 행렬의 특성방정식: λ² − (tr A)λ + det A = 0.
  • tr 과 det 만 알면 고유값의 합과 곱을 바로 알 수 있다.
  • 단답형은 ‘구하는 대상’(λ² 인지 λ 인지)을 마지막에 다시 확인한다.

■ 정석 풀이

  1. 특성방정식: λ² − (5 + 2)λ + (5·2 − 2·2) = λ² − 7λ + 6 = 0
  2. (λ − 1)(λ − 6) = 0 → λ = 1, 6
  3. 큰 값 6 이므로 λ² = 36

[단축 풀이]

tr = 7, det = 6 → 합이 7, 곱이 6 인 두 수는 1 과 6 (바로 판별)

■ 계산 검증

고유값을 수치로 계산하면 (6, 1) ✓. A(2,1)ᵗ = (12, 6)ᵗ = 6(2,1)ᵗ 로 λ = 6 의 고유벡터를 확인했다.

■ 선택지·오답 분석

답안 작성단답형이므로 보기가 없다. 구하는 값은 λ² = 36 이다 (λ = 6 이라고 쓰지 않도록 주의).
흔한 실수큰 고유값 6 만 쓰고 제곱을 빠뜨리거나, 1 + 36 = 37 처럼 두 고유값을 모두 제곱해 더하는 경우

■ 함정 포인트

문제가 묻는 것이 λ 가 아니라 λ² 임을 놓치는 실수. 마지막에 질문을 다시 읽어라.

■ 변형 출제

고유값이 1, 6 이므로 det A = 6, tr A = 7. 값을 거꾸로 주는 역문제로도 출제된다.

오답 원인 태그: 요구값 재확인 누락

10정답 7적분 · 절댓값 정적분

■ 문제

정적분 ∫02 |x2 − 2x| dx = p/q (p, q는 서로소인 자연수) 일 때, p + q 의 값을 구하시오.

■ 출제 의도

절댓값 안의 부호를 구간별로 판단해 정적분을 정확히 계산하는지 확인한다.

■ 핵심 개념

  • 절댓값 안의 식의 부호가 바뀌는 지점(영점)을 먼저 찾아 구간을 나눈다.
  • [0, 2] 에서 x(x − 2) ≤ 0 이므로 부호를 뒤집어 적분한다.
  • 단답형 답안은 p + q 처럼 묻는 형식에 맞춰 마지막에 변환한다.

■ 정석 풀이

  1. x² − 2x = x(x − 2) ≤ 0 (0 ≤ x ≤ 2) → |x² − 2x| = 2x − x²
  2. ∫₀² (2x − x²) dx = [x² − x³/3]₀² = 4 − 8/3 = 4/3
  3. p = 4, q = 3 → p + q = 7

[단축 풀이]

그림으로 보면 y = x² − 2x 는 [0, 2] 에서 x 축 아래이므로 넓이 = 포물선·x 축 넓이 (1/6 공식: 8/6 = 4/3)

■ 계산 검증

구간을 쪼개 수치적분하면 1.33333 = 4/3 ✓.

■ 선택지·오답 분석

답안 작성정적분 값은 4/3 이고 요구하는 답은 p + q = 4 + 3 = 7 이다.
흔한 실수절댓값을 무시하고 ∫(x² − 2x) = −4/3 을 계산해 음수 값이 나오는 경우 / 4/3 자체를 답으로 쓰는 경우

■ 함정 포인트

절댓값을 벗길 때 부호를 판단하지 않으면 −4/3 이 나온다. 정적분 값이 면적이므로 양수여야 한다.

■ 변형 출제

구간이 [0, 3] 이면 4/3 + 4/3 = 8/3 (p + q = 11).
