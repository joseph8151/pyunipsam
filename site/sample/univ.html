01정답 ③극한 · 테일러 전개

■ 문제

limx→0 (e2x − 1 − 2x) / x2 의 값은?

■ 출제 의도

0/0 꼴에서 테일러 전개 또는 로피탈 정리를 선택해 빠르게 계산하는지 확인한다.

■ 정석 풀이

  1. e2x = 1 + 2x + (2x)²/2! + … = 1 + 2x + 2x² + …
  2. 분자 = 2x² + (고차항) → 극한 = 2

[단축 풀이]

로피탈 2회: (2e2x − 2)/(2x) → 4e2x/2 → x=0에서 2

■ 계산 검증

x = 0.01 대입: (e0.02 − 1.02)/0.0001 ≈ (1.0202013 − 1.02)/0.0001 ≈ 2.01 → 2에 근접한다.

■ 선택지·오답 분석

①0 = 1차항이 소거되는 것만 보고 0으로 판단
②1 = ex 전개 계수를 그대로 사용(2x → x)
③정답
④4 = (2x)² 에서 1/2! 을 누락
⑤∞ = 분모가 0이라 발산으로 오판

02정답 ③급수 · 부분분수와 망원급수

■ 문제

급수 Σn=1∞ 1 / (n(n + 2)) 의 값은?

■ 출제 의도

부분분수 분해로 망원급수(telescoping)를 인식하는지 확인한다.

■ 정석 풀이

  1. 1/(n(n+2)) = (1/2)(1/n − 1/(n+2))
  2. 부분합 SN = (1/2)[(1 + 1/2) − (1/(N+1) + 1/(N+2))]
  3. N → ∞ 이면 (1/2)(3/2) = 3/4

[단축 풀이]

남는 항은 처음 두 항(1, 1/2)뿐이다. (1/2)(1 + 1/2) = 3/4

■ 계산 검증

S₁ = 1/3, S₂ ≈ 0.458, S₃ ≈ 0.525, S₄ ≈ 0.567, S₅ ≈ 0.595 … 가 0.75에 접근한다.

■ 선택지·오답 분석

①1/2 = 앞의 계수 1/2만 남기고 괄호 안을 1로 계산
②2/3 = 부분합이 접근하는 값이 아님(부분합 검산으로 배제)
③정답
④5/6 = 부분합이 접근하는 값이 아님(부분합 검산으로 배제)
⑤1 = 1/n − 1/(n+1) 꼴의 망원급수로 착각

03정답 5적분 · 삼각함수의 거듭제곱

■ 문제

정적분 ∫0π/2 sin3x dx = p/q (p, q는 서로소인 자연수) 일 때, p + q 의 값을 구하시오.

■ 출제 의도

홀수 거듭제곱의 치환 적분(sin 한 개를 떼어 cos로 치환)을 정확히 수행하는지 확인한다.

■ 정석 풀이

  1. sin³x = (1 − cos²x) sin x, t = cos x 로 치환하면 dt = −sin x dx
  2. ∫0π/2 sin³x dx = ∫01 (1 − t²) dt = 1 − 1/3 = 2/3
  3. p = 2, q = 3 → p + q = 5

[단축 풀이]

월리스 공식: ∫0π/2 sin³x dx = (2/3)·1 = 2/3 (홀수 차수: (n−1)!!/n!!)

■ 계산 검증

정적분 값 2/3 ≈ 0.667. sin³x ≤ sin x 이고 ∫0π/2 sin x dx = 1 이므로 값은 1보다 작다 ✓.

■ 선택지·오답 분석

답안 작성단답형은 보기가 없으므로 값을 직접 도출해야 한다. 답은 p+q = 5 (2/3 자체를 쓰지 않도록 주의).
흔한 실수치환 후 상·하한을 바꾸지 않거나 부호(−)를 처리하지 않아 −2/3 또는 1/3 이 나오는 경우
